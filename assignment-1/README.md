# Programming for AI — Assignment 01

Simple student-style Python solutions for the five questions in the assignment.

## Files
- `Q1_student_result.py` — Student result management, grades, highest percentage, and `results.txt`.
- `Q2_sentence_analysis.py` — Sentence analysis and `word_analysis.txt`.
- `Q3_shopping.py` — Shopping bill, discount, most expensive product, and `bill.txt`.
- `Q4_calculator.py` — Calculator with separate functions and repeat option.
- `Q5_restaurant.py` — Restaurant ordering and `orders.txt`.

## How to run
Install Python 3, open a terminal in this folder, and run one file at a time:

```bash
python Q1_student_result.py
python Q2_sentence_analysis.py
python Q3_shopping.py
python Q4_calculator.py
python Q5_restaurant.py
```

The text files are created in the current working directory when you run the corresponding program.
